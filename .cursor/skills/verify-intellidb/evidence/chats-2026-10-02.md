## Driving notes for future runs

- The plus button is hover-revealed (`invisible` until row hover). Hidden
  elements skip hit testing, so a CDP click without a preceding
  `Input.dispatchMouseEvent mouseMoved` falls through to the row div. Hover
  first, then click.
- `drive.mjs click` is left-button only. Radix context menus need a
  right-button dispatch (see `/tmp/intellidb-rclick.mjs` used this run; worth
  promoting into the skill if context menus recur).
- `:has-text()` is not a valid querySelector; tag targets with a data
  attribute via `eval`, then click the attribute selector.
